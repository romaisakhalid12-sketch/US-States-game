# US-States-game
Test your knowledge of U.S. geography with this interactive Python game! Guess all **50 U.S. states** while viewing a map. Correct guesses are displayed in their proper locations, and if you choose to exit early, the game generates a list of the states you missed.

## About the Project

This game uses **Python Turtle Graphics** to display a blank map of the United States and **Pandas** to manage state data. Players enter state names one by one, and each correct answer is written onto the map.

If you exit before guessing all 50 states, the program creates a **`missing_states.csv`** file containing the states you still need to learn.

## Features

-  Interactive U.S. map
-  Correct guesses appear on the map
-  Tracks your progress out of 50 states
-  Generates a list of missed states
-  Built with Python, Turtle Graphics, and Pandas

## How to Play

1. Enter the name of a U.S. state.
2. If your answer is correct, it will appear on the map.
3. Continue until you've guessed all 50 states.
4. Type **Exit** at any time to end the game and generate a list of missing states.
